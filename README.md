# Jogo de Xadrez ♟

Jogo de xadrez em terminal desenvolvido durante o curso de C# do professor Nélio Alves. 

O projeto foi feito para praticar lógica e orientação a objetos, implementando as regras do jogo e a estrutura do tabuleiro.

## Funcionalidades

* Validação de movimentos das peças
* Sistema de xeque e xeque-mate
* Histórico de peças capturadas
* Jogadas especiais (roque, promoção e en passant)
